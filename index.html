How this works

  • When the server starts it scans both drives once (about 2 minutes). After that, Windows reports every file change, and only the folders involved are re-read.
  • Under very heavy disk activity Windows can drop some change reports. When that happens a warning appears in the bar at the top. Click Rescan everything to get exact numbers again.
  • File types and the by-year chart come from the last full scan. Everything else on the page is live.
  • Sizes use the same units as Windows Explorer (1 GB = 1,024 MB). Online-only cloud files (Dropbox, OneDrive) don't use disk space and aren't counted.
  • Folders your account can't open (restore points, other users' files) are left out. That's the hatched part of each drive bar.
  • The page is served only to this computer at 127.0.0.1. Closing the server window stops the updates.
